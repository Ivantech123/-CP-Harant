# Инструкция: как пользоваться поиском юристов через ChatGPT

## Что это такое

Это AI-помощник для поиска юристов на портале Harant.ru. Вы просто описываете свою задачу обычными словами — ChatGPT сам найдёт подходящих специалистов, покажет их профили, рейтинги, опыт и контакты.

---

## Как подключить

1. Откройте [ChatGPT](https://chatgpt.com)
2. Перейдите в **Приложения** → **Новое приложение**
3. Заполните:
   - **Название**: Harant Lawyers
   - **URL MCP-сервера**: `https://cp-harant.vercel.app/api/mcp`
   - **Аутентификация**: Без авторизации
4. Поставьте галочку и нажмите **Создать**

---

## Примеры запросов

### Найти юриста по задаче
```
Мне нужен юрист для развода и раздела квартиры в Москве
```
```
Ищу адвоката по уголовному делу в Саранске, опыт от 15 лет
```
```
Помогите найти юриста по трудовым спорам, меня незаконно уволили, Краснодар
```

### Поиск по специализации
```
Найди юристов по банкротству физических лиц в Екатеринбурге с рейтингом выше 8
```
```
Юристы по ДТП в Казани с бесплатной консультацией
```
```
Адвокаты по уголовным делам в Нижнем Новгороде, стаж от 20 лет
```

### Профиль конкретного юриста
```
Покажи полный профиль юриста: https://harant.ru/lawyers/saransk/naumov-sergej-gennadevich-2/
```
```
Какие судебные дела вёл этот юрист? https://harant.ru/lawyers/moskva/ivanov-ivan-ivanovich/
```

### Сравнение юристов
```
Сравни этих двух юристов и скажи кто лучше:
https://harant.ru/lawyers/saransk/kamodin-aleksandr-aleksandrovich/
https://harant.ru/lawyers/saransk/chernyh-tatyana-sergeevna/
```

### Статистика города
```
Сколько юристов по семейным делам в Саранске? Какой средний рейтинг?
```

## Что показывает система

По каждому юристу вы получите:

| Данные | Описание |
|--------|----------|
| ⭐ Рейтинг | Оценка на Harant.ru (0–10) |
| 📅 Стаж | Количество лет практики |
| ⚖️ Дела | Количество судебных дел |
| 💬 Отзывы | Количество отзывов клиентов |
| 📋 Специализации | Области права |
| 📞 Контакты | Телефон, Telegram, WhatsApp |
| 💰 Цены | Стоимость консультации |
| 🏛️ Суды | В каких судах работал |

## Советы

- **Называйте город** — поиск точнее с указанием города
- **Описывайте проблему** — "хочу развестись" лучше чем "семейное право"
- **Просите сравнить** — если нашли несколько кандидатов, попросите ChatGPT сравнить их
- **Уточняйте бюджет** — можно попросить только юристов с бесплатной консультацией

Вы можете говорить как угодно — система поймёт:

| Что вы говорите | Что ищется |
|-----------------|------------|

| дтп, авария, осаго | Автоюристы |
| банкрот, долги, списание | Банкротство |
| жкх, квартира, выселение | Жилищные вопросы |
| алименты, содержание детей | Алименты |
| увольнение, зарплата, труд | Трудовое право |
| земля, участок, межевание | Земельные вопросы |
| наследство, завещание | Наследство |
| штраф, гибдд, протокол | Административное право |
